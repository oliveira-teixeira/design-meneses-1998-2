# Meneses 1998

A design canvas with six artboards in the Meneses 1998 direction for the site of Ana Luíza Meneses: home, visual art, reel, about, the estrondo work page and the phone home screen. The content is in Portuguese.

Live: https://oliveira-teixeira.github.io/design-meneses-1998-2/

## Stack

- Plain HTML and CSS, no JavaScript in the artboards
- Google Fonts: Newsreader, Courier Prime
- That That New Pixel embedded as a base64 woff2 font
- Photographs next to the artboards in `boards/`
- Canvas viewer in `index.html`: plain HTML and CSS with a few lines of JavaScript that scale each artboard to fit the window
- Originally a canvas page published from Claude Code. Only the design was exported: each artboard was flattened into a standalone static page and the canvas note sits above the artboard it was placed next to. The canvas editor itself is not included

Exported from a claude.ai artifact on 9 Oct 2026.
